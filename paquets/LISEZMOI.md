# Dossier des paquets partagés

Chaque fichier `.json` rangé ici s'ouvre par un lien : pour `logement-a2.json`, l'adresse est

```
https://julla78.github.io/elefiches/?paquet=logement-a2
```

Pour obtenir un fichier : dans Éléfiches, « Espace enseignant », bouton « Exporter » du paquet. Le fichier contient les fiches, leurs images et leurs sons.

Nom du fichier : lettres sans accent, chiffres et tirets seulement, sans espace (`week-end-a-londres-a1.json`).
